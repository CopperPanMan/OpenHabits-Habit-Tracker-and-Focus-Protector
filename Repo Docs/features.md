# Feature guides

Finish the [basic setup](setup.md), then choose the features you want. Each guide covers the extra steps needed for that feature.

| I want to… | Guide |
| --- | --- |
| Track tasks, numbers, text, or timestamps; log several things together | [Create and log metrics](guides/metrics.md) |
| Start and stop a work, exercise, or other timer | [Track time](guides/timers.md) |
| Log using QR codes, NFC, Siri, widgets, or automations | [Quick launchers](guides/launchers.md) |
| Earn points and track streaks | [Points and streaks](guides/points-streaks.md) |
| Get performance feedback or a "what next?" prompt | [Insights and prompts](guides/insights.md) |
| Redirect distracting iPhone apps | [iOS app protection](guides/ios-lockouts.md) |
| Block until tasks are done, limit screen time, or use different rules on different days | [Blocking rules and presets](guides/rules.md) |
| Apply rules to websites on a computer | [Chrome website protection](guides/chrome.md) |
| Connect tasks in Notion | [Notion sync](guides/notion.md) |
| Schedule reminders that know whether I finished a task | [Calendar Alarms integration](guides/calendar-alarms.md) |
| Chart my history, change timezone behavior, back up, update, or fix an issue | [Maintenance and troubleshooting](guides/maintenance.md) |

For custom clients and raw configuration, see the [Developer reference](README.md).
